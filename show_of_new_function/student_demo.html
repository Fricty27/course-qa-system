泰勒展开的余项主要有以下几种形式：

  1. 皮亚诺余项（Peano）：Rₙ(x) = o((x-x₀)ⁿ)，即余项是 (x-x₀)ⁿ 的高阶无穷小。适用于定性分析，不给出误差的具体界。
  2. 拉格朗日余项（Lagrange）：Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x-x₀)ⁿ⁺¹，其中 ξ 介于 x 与 x₀ 之间。可用于估计余项大小，给出误差界。
  3. 柯西余项（Cauchy）：在某些证明中更为方便。
  4. 积分余项：最为精确，但计算复杂。

实用建议：定量估计误差时用拉格朗日余项；定性讨论极限时用皮亚诺余项更简洁。
